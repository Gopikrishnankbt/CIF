# CalClone Slot Booking App

A frontend slot-booking web app inspired by cal.com, including:

- Dashboard analytics
- Booking management
- Event type management
- Public booking flow
- Availability overview
- Teams & round-robin concepts
- Workflow automation view
- Routing form logic preview
- Integrations and app store pages
- Billing and settings pages

## Run locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`
